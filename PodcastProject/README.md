# 🎧 Podcast Scheduler (JavaFX)

A desktop application built using JavaFX to manage and schedule podcast episodes.

---

## 🚀 Features
- Create podcast episodes
- Set duration, type, date, and time
- Schedule episodes
- Publish selected episodes
- Save all data

## ▶️ How to Run
1. Clone the repository
2. Open in IntelliJ IDEA
3. Make sure JavaFX SDK is configured
4. Run the main class
